# Stack selection: TypeScript, Fastify, React/Vite, SQLite, single deployable

GreenOps v1 is TypeScript throughout, with a Node.js + Fastify backend and a React + Vite frontend, persisted to SQLite, shipped as one application rather than separately deployable services. We considered splitting frontend and backend into independently deployable services and using a hosted database, but v1 serves a single Analyst and a single Building (ADR-0002) with no concurrent multi-user load to justify that operational overhead. The trade-off: SQLite constrains concurrent writes and horizontal scaling, and the single-deployable shape means frontend and backend can't be scaled or deployed independently — both acceptable while the core Consumption-and-Cost trend loop is unproven, revisitable once real usage demands it.
